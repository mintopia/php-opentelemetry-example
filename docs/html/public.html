Introduction

This PHP application is designed to be an example of using OpenTelemetry inside an application to export metrics, logs and traces to any OpenTelemetry compatible provider.

Open Telemetry is a vendor-neutral CNCF project for standardised observability. It is widely supported by all observability providers.

Source code for this can be found at https://github.com/mintopia/php-opentelemetry-example.

Architecture

The main application is a Laravel 12 application running in a docker container using FrankenPHP. There is a scheduler container running a task that exports metrics every minute. The metrics themselves are stored in a redis compatible cache, eg. Redis, ElastiCache, Valkey.

An Open Telemetry Collector container is running as a sidecar and takes the metrics and pushes them based on the configuration in otel-collector-config.yaml in the root. This is using the AWS Open Telemetry Collector as it allows easy submission of data to CloudWatch and X-Ray. The supplied configuration also has an example of sending data to Honeycomb.

Metrics

There are 3 metrics we export every minute.

  • widget-count - An Open Telemetry Counter. This can only go up and is incremented using the /count endpoint.
  • widget-number - An Open Telemetry Up Down Counter. This can be increased and decreased using the /up and /down endpoints.
  • load - An Open Telemetry Gauge. This can be set using the /load endpoint. It is intended to be used to simulate load on the application and to be used for autoscaling decisions.

Technology Choices

Laravel 12 was used as an easy to implement and understandable PHP framework for this. The Open Telemetry integration is custom written using the Open Telemetry SDK. I considered using the Spatie Laravel Open Telemetry library, but found that it wasn't outputting OTLP HTTP JSON formatted requests to the OpenTelemetry collector.

Laravel Octane and FrankenPHP are used for running the application. This would allow for high performance in production environments.

PHPStan and PHP Code Beautifier and Fixer is used to ensure code quality and adherence to standards.
